# Dong Li / FSI Lab website

This repository is a dependency-free static website ready for GitHub Pages.

## Publish at GitHub Pages

1. Create (or rename) the repository to `leetton.github.io` for the address `https://leetton.github.io`, or use any project repository for `https://leetton.github.io/REPOSITORY-NAME/`.
2. Push these files to the `main` branch.
3. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, and select `main` and the repository root (`/`).

For a project-site address, all links are relative and work as-is. Update the contact details and news in `index.html` as needed.
